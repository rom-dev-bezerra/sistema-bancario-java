#Sistema Bancário em Java

Projeto desenvolvido em Java com o objetivo de praticar e consolidar conceitos fundamentais de Programação Orientada a Objetos (POO).

A aplicação simula operações básicas de uma conta bancária através de uma interface executada no terminal, permitindo trabalhar com conceitos como classes, objetos, métodos, atributos, construtores, encapsulamento da lógica e estruturas de repetição e decisão.

🚧 Projeto em desenvolvimento — novas funcionalidades estão sendo adicionadas conforme avanço nos estudos de Java.

##Funcionalidades

Atualmente, o sistema possui:

- Cadastro de contas bancárias
- Consulta de saldo
- Depósito
- Saque
- Busca e seleção de conta
- Menu de operações no terminal
- Estrutura preparada para novas operações
-

##Exemplo de funcionamento

Ao executar a aplicação, o usuário pode interagir com o sistema através do terminal.

Exemplo:

===== SISTEMA BANCÁRIO =====

1 - Acessar conta
2 - Sair

Escolha uma opção:

Após acessar a conta:

===== MENU =====

1 - Mostrar saldo
2 - Sacar
3 - Depositar
4 - Transferir
5 - Sair
